## 简介

一个纯静态的多页作品集，用「项目档案 + 成长轨道 + 六面探索」三种方式讲同一件事：我怎么把模糊的问题拆成可验证、可交付的路径。

- **首页**：三个精选项目 —— 伪人读书、求职工作台、华飞智营
- **项目档案**：九个项目，包含真实产品截图、我的职责、当前状态与关键决策
- **成长轨道**：18 个经历节点，可在三维轨道与列表之间切换
- **六面探索**：收窄 / 验证 / 沉淀 / 分工 / 落地 / 交付 六个视角，每个视角关联真实经历

页面不含构建步骤，只依赖 `style.css`、`site.js`、`media/` 下的截图，以及 `assets/cold/orbit-archive-v13.html` 这个自包含的三维轨道组件。

## 本地预览

```bash
python -m http.server 8899 --bind 127.0.0.1
```

然后打开 `http://127.0.0.1:8899/index.html`。直接双击文件也能看，但三维轨道与部分交互建议走本地服务。
