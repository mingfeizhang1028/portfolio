WINDOWS · AI 陪伴 / PROJECT ARCHIVE

芽砚 Deskpet

让陪伴安静地存在于桌面，不打断正在进行的工作。
产品形式Windows 透明置顶桌面伙伴
我的工作产品定位、交互设计、桌面功能与验证
核心体验流式聊天、专注陪伴、任务记录
查看 GitHub 项目 ↗
01

从陪伴需求到产品定位

长时间使用电脑时，需要的是随时可用、但不过度打断的陪伴。我将产品设计成停留在桌面角落的轻量伙伴，避免把专注时间变成需要频繁回应的养成任务。

02

低干扰的桌面交互

使用透明置顶的桌面形态，围绕聊天、专注计时和任务记录组织功能；专注陪伴支持 1—120 分钟，让使用者能自行决定互动节奏。

03

动画异常时保留核心功能

将桌宠动画渲染与主程序分开处理；渲染出现异常时回退为静态形象，让聊天与专注功能继续可用。

04

记忆由用户决定

对候选长期记忆加入确认环节，区分主动保存和模型推断，避免将临时对话直接写成永久设定。

05

流式模型接入与本地隐私

支持 Responses API 与 Chat Completions 两条流式聊天路径；API 凭据通过 Windows 凭据管理器保存，不设独立服务端。将响应能力与界面状态分开，使聊天体验不依赖动画正常运行。

06

水彩动画的可复用生产流程

整理 20 个动画剪辑及 505 帧水彩素材，通过抠图、对齐、接缝检查与质量检查拼图处理画面；使用脚本组织重复步骤，便于后续增补动作。

07

运行与测试

Windows 本机已可运行，核心逻辑整理有 56 项离线单元测试。对不稳定的动画渲染和可选语音提供降级路径，减少非核心功能对聊天、专注体验的影响。
