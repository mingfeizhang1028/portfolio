3D 互动产品 / PROJECT ARCHIVE

决策骰子

把日常的小选择，变成一次有真实手感的投掷。
产品形式手机浏览器 3D 决策工具
我的工作玩法、视觉交互、物理手感和上线验证
项目特点真实刚体投掷与判面一致性
在线体验决策骰子 ↗查看 GitHub 项目 ↗
01

从纠结到行动

在“吃什么、谁先做”这类低风险日常场景里，用户未必缺少信息，而是需要一个愿意接受结果的决定动作。我选择用投骰子的仪式感推动行动。

02

真实物理，而不是预设动画

使用刚体模拟投掷与碰撞，并通过朝上面的判定让画面和结果一致。手感、落定反馈与可见结果共同决定体验。

03

不同场景对应不同玩法

设计对决、选号、多数决等使用方式，以及滑动、摇一摇、键盘等交互入口，让投骰不只是一段表演动画。

04

浏览器端交付

产品以网页形式运行，采用自动化脚本检查主要投掷流程，并通过 GitHub Pages 进行发布。

05

真实刚体物理与判面

使用 cannon-es 计算投掷与碰撞，再根据骰子的朝向判断落定点数，让界面看到的结果与实际判定保持一致。

06

多颗骰子的稳定性

支持单次最多 12 颗骰子，加入防飞出约束、落定超时保护及按数量调整视角的处理，避免骰子越界或迟迟没有结果。

07

从交互到发布

提供对决、选号、多数决三种主要玩法，以及多种材质、主题和输入方式；配套 6 条端到端浏览器测试脚本，并通过 GitHub Actions 自动部署。
